# Application Access Authorization & Permission Requests

## Overview
Procedures for requesting access to corporate SaaS applications, internal portals, database clusters, and Active Directory groups.

## Request Process
1. Access requests require line manager approval before provisioning.
2. Submit a Service Request specifying the application name (e.g., Salesforce, Jira, SAP, GitHub Enterprise) and access tier (Read-Only, Standard, Administrator).
3. Temporary access is auto-revoked after 90 days unless renewed.
