# Corporate Laptop Performance Optimization Guide

## Overview
Guidelines for resolving slow system response times, high CPU/memory utilization, and thermal throttling on enterprise laptops.

## Resolution Steps
1. **Check Task Manager**: Press `Ctrl + Shift + Esc` to view CPU and Memory consumers. End unresponsive processes.
2. **Clear Temporary Files**: Run Disk Cleanup or delete contents of `%TEMP%` directory.
3. **Manage Startup Items**: Disable unnecessary third-party background applications under Task Manager > Startup.
4. **Update System Drivers**: Open Software Center or System Update manager to apply critical hardware firmware and graphics updates.
5. **Reboot**: Perform a clean system restart at least once per week.
